# MythicAtlas / 新山海图志

MythicAtlas 是一座以《山海经》视觉语言重述真实世界奇境的沉浸式数字图志。项目从固定民用日期 `2026-01-01` 起，每日只解锁一处地点；访客可以在实时山海天球上回望已解锁的往昔记录、阅读神话异志与地理实纪，并把喜欢的地点钤入仅存于当前设备的行旅手卷。

## 核心体验

- 392 处唯一的真实世界地点，索引连续，覆盖六大洲与南极洲
- 每个地点包含真实经纬度、地域、国家、年代、地形、气候五行、守护灵、神话双句、异闻、真实历史与独立色彩主题
- 以民用日而非运行时长计算解锁，支持本地时间与 UTC 标准
- 所有入口统一经过未来日期门禁，档案、星位、URL 侧入口与持久化数据都不能越过当前解锁边界
- Three.js 实时天球，含 7600 个高质量粒子、地貌位移、Fresnel 大气、流动墨雾、星位射线选择与环形仪轨
- GSAP 球面相机转场，Unreal Bloom、胶片颗粒与暗角后处理
- Web Audio API 合成风、水、五声音阶、纸页与青铜钤印声，不依赖外部音频文件
- 横向往昔舆图、神话与地理双层阅读、钤印收藏、发现记录和上次访问位置
- WebGL 不可用时自动切换为本地丝绢星图，内容与时间门禁保持完整
- 桌面、触控设备、键盘、减少动效和降低透明度偏好均有独立适配

## 时间门禁

默认首日为 `2026-01-01`。`src/core/timeLock.ts` 只按所选时间标准中的民用日期计算 `epochDay`，因此页面刷新、系统夏令时变化或设备休眠不会多解锁地点。

解锁规则如下：

1. 启动日前没有任何地点可访问。
2. 第 0 天只开放索引 0，之后每日增加一个可访问索引。
3. `unlockedCount` 永远不超过目录总数。
4. 任何未来索引默认抛出 `FutureUnlockError`，只有明确请求安全钳制时才返回最近可访问索引。
5. 本地存储中的地点 ID 每次读取和写入都会重新经过当前解锁集合过滤，系统时钟回拨后也不会保留越界记录。

完整边界测试覆盖启动前、首日、跨月、跨年、UTC、本地时区、23 小时和 25 小时夏令日、时钟回拨、损坏存储与未来 ID 注入。

## 本地运行

需要 Node.js 22 或兼容 Vite 8 的现代 Node.js 版本。

### Windows 双击打开

桌面快捷方式 `山海经3D-一键启动.lnk` 会在后台启动当前仓库的 Vite 开发服务，确认页面健康后自动用默认浏览器打开，不显示 PowerShell、CMD 或 Vite 窗口。保存源码后刷新即可读取当前仓库；重复双击会复用同一开发实例；如果 4173 被其他程序占用，会安全选择后续空闲端口，不会结束未知进程。

启动器文件位于 `scripts/`。桌面快捷方式使用开发模式以支持热更新；直接运行 `scripts/Start-MythicAtlas.ps1` 仍可启动生产预览，并在生产构建缺失或源文件更新时执行后台构建。两种模式的日志都写入 `%LOCALAPPDATA%\MythicAtlas\logs`，不会污染仓库。重新创建快捷方式可运行 `scripts/Install-MythicAtlasShortcut.ps1`。

### 命令行开发

```powershell
cd F:\AIagent\GithubProjects\MythicAtlas
npm ci
npm run dev
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。

生产构建与预览：

```powershell
npm run build
npm run preview
```

完整验证：

```powershell
npm run check
```

`npm run check` 会执行全部 Vitest 测试、TypeScript 无输出类型检查和 Vite 生产构建。

| `index.html` | 页面语义骨架、首屏、抽屉、档案与无脚本提示 |

## 性能与隐私

- 初始应用逻辑与 Three.js 场景分块加载，页面先建立时间门禁和可读内容，再初始化实时天球。
- 场景根据硬件、视口、帧率与减少动效偏好选择 high、balanced、low 或 fallback 质量。
- 非当前档案卡片使用浏览器内容可见性优化；暂停页面时停止动画与声景。
- 字体和图像全部随站点发布，不依赖第三方 CDN。
- 不使用账户、Cookie、分析脚本或远程数据库。
- 发现、阅读和钤印记录只保存在浏览器 `localStorage`；存储不可用时退回当前会话内存。

### 静态部署的门禁边界

当前版本是纯静态客户端应用。时间门禁会约束页面、星位、档案选择、上次访问恢复和本地持久化，构建时也不发布 Source Map；但它不是服务器授权或数字版权保护。完整目录仍随客户端代码发布，设备所有者也能修改系统时间。因此，“未来地点不可访问”在这里指正常应用交互与本地状态不能越界，不代表能抵抗拥有 DevTools 和本机控制权的对抗者。

若上线业务需要权威且不可绕过的每日发布，应由服务端或边缘函数使用可信时间，只返回当日已开放记录，并让客户端消费签名清单。本仓库没有伪装成已经存在的服务端安全边界。

## GitHub Pages

推送到 `main` 后，`.github/workflows/pages.yml` 会在 Node.js 22 上安装锁定依赖、运行完整检查、构建 `dist`，再把构建产物部署到 GitHub Pages。Vite 使用相对资源基址，因此可用于项目子路径。

仓库当前未声明或虚构公开演示地址。部署成功后的真实地址以 GitHub Actions 与 Pages 设置页为准。

## 视觉素材

降级丝绢星图由 OpenAI 内置图像生成工具按本项目的深玄墨、朱砂、矿物青绿与泥金视觉方向生成，之后作为本地静态资产随仓库发布。实时天球、纹理、雾、星位和后处理均由代码程序化生成，不请求外部贴图。
